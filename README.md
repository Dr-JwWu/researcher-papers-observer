# ResearcherPapers Observer

具身智能与手术机器人／手术AI中文文献阅读。

网站：https://dr-jwwu.github.io/researcher-papers-observer/

当前研究窗口：2026-10-08 至 2026-10-20（UTC）。共 296 篇。按北京时间每天03:00自动更新，异常见网站当天栏目；来源限制解除后继续补采。

本仓库仅静态网页与白名单研究产物，不含后端、数据库、私有证据或笔记。中文阅读以摘要证据为主；来源确认无摘要时仅展示经核标题与已有事实，不镜像受限内容。
